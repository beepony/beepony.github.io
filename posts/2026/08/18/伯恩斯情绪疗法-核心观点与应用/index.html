🧠 伯恩斯情绪疗法 · 核心观点与应用

来源：David Burns《Feeling Good》/《伯恩斯新情绪疗法》| 标签：#认知行为 #CBT #情绪管理 #思维陷阱

一、核心观点

1. 情绪的因果链：A → B → C

  • A（Adversity 事件）→ B（Belief 想法）→ C（Consequence 情绪）
  • 情绪 C 不直接来源于事件 A，而是来源于你对 A 的想法 B
  • 改写 B，就能改变 C；这是 CBT 整套技术的根基

2. 十种认知扭曲（识别清单）

类型一句话定义典型句式
全或无思维非黑即白，没有中间地带“这次搞砸了，我就是个失败者”
过度概括一次失败 = 永远失败“又搞砸了，我永远做不好”
心理过滤只看负面，忽略正面“他夸了我三句，但那句批评才是关键”
贬低正面把好事解释成”不算”“他只是客气，不是真的认可”
武断推断没证据就下负面结论“她没回消息，肯定是生气了”
放大缩小放大自己错处，缩小自己优点“这点小成功不值一提”
情绪化推理“我觉得是这样 = 事实是这样”“我觉得自己是废物 → 我就是废物”
应该论断用”应该”自我施压“我应该做得更好”
标签化把行为上升为人格评价“我是 loser”
个人化把外部事件归因为自己“团队出问题，都是我的锅”

3. 工具箱

  • 三栏日志：事件 → 自动想法 → 更平衡的想法
  • 反驳信念表：列出证据反方 + 证据正方 + 更平衡的陈述
  • 成本收益分析：维持当前扭曲想法的代价 vs 改写的代价
  • 情绪-想法溯源：从 C 倒推 B，再验证 B 是否成立

二、工作场景应用

同事/上级没回消息

  • 自动想法：“他对我不满”（武断推断）
  • 改写：“他可能在忙、没看到、或在处理更紧急的事”
  • 行动：等 24h 再决定是否跟进；不直接推断意图

项目被否

  • 自动想法：“我能力不行”（标签化 + 全或无思维）
  • 改写：“这次方案匹配度问题，不是人。拆分：可改进部分是 X、不可控部分是 Y”
  • 行动：向决策方问清改进方向；把反馈拆成”决策质量”和”自我评价”两条线

会议发言被打断

  • 自动想法：“被针对了”（个人化）
  • 改写：“对方可能也有时间压力或表达冲动”
  • 行动：当场不反击，事后单独沟通

三、生活场景应用

亲密关系摩擦

  • 扭曲类型：应该论断（“他应该记得我们的纪念日”）
  • 改写：“我可以直接告诉他我的期待，而不是等他’应该知道’”
  • 行动：用”我希望 / 我需要”句式替代”你应该”

失眠 + 反刍

  • 扭曲类型：灾难化 + 应该论断（“明天一定搞砸 / 我应该早点睡”）
  • 改写：把”明天一定搞砸”写成”我已经准备好的具体步骤有 X、Y、Z”
  • 行动：睡前 30 分钟做 5 分钟三栏日志 + 把”应该早点睡”换成”我打算 23 点关灯”

社交媒体比较

  • 扭曲类型：全或无思维（“他们活得多姿多彩，我就是个 loser”）
  • 改写：“对方展示的是高光，我看到的是全集吗？”
  • 行动：固定浏览时段 + 每次浏览后写一行”此刻的真实感受”

四、可立即上手的微习惯

  1. 三栏日志：每天睡前 1 条，2 周一个周期
  2. 情绪溯源：每次情绪强度 > 6/10 时，问”我在想什么？”
  3. 标签化自查：把”我是 X”改成”我这次 X”，把人格评价降级为行为评价

五、与《思考，快与慢》的衔接

  • 伯恩斯负责改写（怎么把自动想法替换成平衡想法）
  • 卡尼曼负责识别（为什么系统 1 会自动产出这些扭曲想法）
  • 完整链路：识别（卡尼曼）→ 标注扭曲类型（伯恩斯）→ 改写（伯恩斯）→ 行为固化
