    Introduction

    AJAX isn't a new programming language, but a technique for building fast, dynamic pages. With it, you can

    • Update content without reloading the page
    • Request data from a server
    • Download data from a server
    • Send data to a server in the background

    Definition

    AJAX = Asynchronous JavaScript and XML. The name is a bit misleading, because you can use AJAX even if you don't know XML.

    Applications

    Apps that use AJAX include Google Maps, Gmail, YouTube, Facebook, and more.

    How AJAX Works

    AJAX Is Based on Internet Standards

    AJAX is based on internet standards, mainly these two

    • XMLHttpRequest object (to retrieve data from a web server)
    • JavaScript/DOM (to display/use the data)

    AJAX became popular in 2005 because of Google Suggest. As you type in the search box, JavaScript sends data to the server, and the server returns a list of suggestions based on your input.

    XMLHttpRequest object

    The XMLHttpRequest object is the foundation of AJAX. All modern browsers support the XMLHttpRequest object, which is used to exchange data with a server.

    Create an XMLHttpRequest object
    xhr = new XMLHttpRequest();

    The definition makes it clear that AJAX is asynchronous, so the third argument to open() is set to true. Asynchronous execution is great news for developers. Server-side work is usually slow, and before AJAX, many operations could cause the page to hang or stop. With AJAX, JavaScript no longer has to keep waiting for the server's response

    • Scripts can keep running while waiting for the server's response
    • The response can be handled as soon as it's ready.
