    • Basic Concepts of Expect

    I often need to scp local content to a server and run the same commands on the server, and I learned that exepect scripts can automate this, so I'm writing it down. Let computers handle simple, repetitive work as much as possible: automate processes and tasks to get more done.

    When you need to interact with the console, you'll find that TCL-Expect is an incredibly useful tool that can rescue you from repetitive, tedious tasks. Work you once had to do by hand can now be done easily with an expect script. These scripts are a lot like shell scripts, but they use the .tcl extension and are invoked with #!.

    Puts & Output

    shell scripts usually print with echo, while expect uses puts, which is a lot like Ruby.

    puts "I am performing a output command"

    This prints I am performing a output command, just like echo.

    By default, the script prints the commands you're running. That's useful for testing, but not always needed in production or day-to-day use. To show only the puts text and hide other commands, use:

    log_user 0

    Or you can force it to show commands and their responses with:

    log_user 1
