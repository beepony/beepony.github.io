    JS Debugging

    IE, Firefox, and Chrome can all be used for debugging

    [Elements] The left side of this tab lets you view and edit the page's HTML structure; the right side lets you view and edit an element's CSS
    [Network] This tab analyzes the site's network requests and shows each request's headers, response headers, and response body.
    [Sources] This tab shows requested resources, including CSS, JS, and images. You can also set all kinds of breakpoints here.
    [Timeline] This tab shows JS execution time and page rendering time
    [Profiles] This tab is mainly for performance tuning, including CPU time and memory usage
    [Audits] This tab helps optimize front-end pages and speed up page loading
    [Console] This tab is the JS console. You can view errors, print debug output (console.log()), write test scripts, and even use it to explore JavaScript APIs
    [Other] Click the phone icon to debug pages in mobile mode
