    • Building a Free Blog with Jekyll and GitHub Pages

    I set up another blog as a backup (in case Farbox goes away): binge. Here's a quick overview of how I built it.

    1. Local Setup

    Setting up Jekyll locally is similar to creating a new Rails project. First, install Jekyll
    sudo gem install jekyll
    Then create a Jekyll project
    jekyll new test
    Go into the project and start the server
    cd test
    jekyll s
    Open 127.0.0.1:4000 in your browser to preview it. Your local setup is done.

    2. Publishing to GitHub

    4. Writing Posts

    Each Jekyll post is a Markdown file stored in the _posts directory. Post filenames follow a fixed format, and Jekyll generates each post's permalink from its filename. The format is YYYY-MM-DD-post-name.md, where YYYY is the year, MM is the month, and DD is the day. For example: 2015-05-18-test.md
    Besides the filename format, each post needs front matter before you write it. Front matter goes between two lines of three dashes. In it, you can set predefined global variables, and Jekyll uses them to generate the post page. Here's the front matter for this post:

    For other front matter settings, see frontmatter
    For Markdown syntax, see A Markdown Guide for Beginners

    5. Adding Comments

    For comments, I used the well-known service Disqus. The usual steps: sign up, sign in, get the code, and add it to the page.
    In Disqus, go to Settings > Add Disqus To Site, click Start Using Engage, open Site profile, fill in the details, choose Auto for Category, and click Finish registration. Then paste the code between the </article> and </div> tags in _layouts/post.html

    And that's a free blog, up and running. Of course, this is only the beginning. The real goal is to keep writing. Happy Blogging :)
